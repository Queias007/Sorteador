# 🎲 Sorteador - Projeto de Sorteio

Bem-vindo(a) ao projeto **Sorteador**! Este é um aplicativo simples para realizar sorteios, criado com HTML, CSS e JavaScript. Ele permite que o usuário insira uma lista de itens e selecione aleatoriamente um deles. 🎉

---

## 🚀 Tecnologias Utilizadas

- <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/html5/html5-original.svg" width="30" height="30"/> **HTML5** - Estrutura básica do aplicativo.
- <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/css3/css3-original.svg" width="30" height="30"/> **CSS3** - Estilização e layout do sorteador.
- <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/javascript/javascript-original.svg" width="30" height="30"/> **JavaScript** - Função principal de sorteio e interatividade.

## 📂 Como Executar o Projeto

## ⚙️ Funcionalidades

- **Sorteio Aleatório**: O aplicativo permite que o usuário insira uma lista de itens e realize um sorteio aleatório entre eles.
- **Interface Simples**: A interface é fácil de usar, com apenas alguns campos de entrada e um botão para realizar o sorteio.
- **Ajustes para Diferentes Dispositivos**: O layout foi desenvolvido para ser responsivo, funcionando bem em dispositivos móveis e desktops.
- **Estilo Clean e Funcional**: A interface foi desenhada para garantir que o usuário tenha uma experiência simples e intuitiva.
